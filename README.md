# KAP Simulator

Қазақ даласындағы survival-экшн: шөлейттегі уран кеніші, 21 ұңғыма, бандиттер, мутанттар, ауа райы мен оқиғалы сюжет.
Unreal Engine 5 ойыны. Тегін.

## ⬇️ Жүктеу

**[Releases](../../releases/latest) бетінен `KAPSimulator_Windows.zip` файлын жүктеңіз.**

1. Zip-ті кез келген папкаға шығарыңыз (мысалы `D:\Games\KAPSimulator`). Zip ішінен тікелей ашпаңыз.
2. `KAPSimulator.exe` файлын ашыңыз.
3. Ойын ашылмаса немесе DLL/DirectX қатесі шықса, алдымен
   `Engine\Extras\Redist\en-us\vc_redist.x64.exe` орнатып, ойынды қайта ашыңыз.
4. Windows SmartScreen «Windows protected your PC» десе: **More info → Run anyway**. Ойын цифрлық қолтаңбамен расталмаған, бұл қалыпты жағдай.

Сақталған ойын: `%LOCALAPPDATA%\KAPSimulator\Saved\SaveGames`.
